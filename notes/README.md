# Learning Notes

This directory contains all study notes recorded during the Linux Kernel Roadmap.

## Current Structure

```text
notes/
├── TEMPLATE.md   # Copy this when starting a new weekly note
└── weekly/       # One file per week: Week01.md, Week02.md, ...
```

## Future Extensions (create on demand)

Add these only when you actually start using them — don't pre-create:

- `notes/monthly/` — monthly retrospectives, once you want a higher-level summary than weekly notes.
- `notes/reflection/` — free-form reflection entries (career, learning process, etc.).
- `notes/cheatsheet/` — quick-reference sheets (e.g. `gdb-cheatsheet.md`, `qemu-cheatsheet.md`) once you've accumulated enough commands worth indexing separately from weekly notes.
